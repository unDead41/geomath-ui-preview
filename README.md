Separate GitHub Pages preview of the four GeoMath entry pages: Home, choose a game, resume and how to play.

- Published frontend branch: `preview-ui-upgrade` (repository root).
- Canonical source: `unDead41/geodecoder`, branch `digitalized-ux-ui-upgrade`.
